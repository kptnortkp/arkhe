- `src/components/forms/field.tsx:39-52` — `FormMessage` with `role="alert"` re-rendering the *same* text (two identical failed logins) is not re-announced; key it by a counter from the action state.

- `src/app/giris/actions.ts:51` — inactive account with correct password gets the generic error; spec wants `Hesabın şu an pasif. Yönetimle iletişime geç.` (PO call; the generic message is safer).
